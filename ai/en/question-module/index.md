# Question Module — author manual

This manual is intended for **question authors** and **content managers** working on their own Isograd platform: producing and publishing questions, subjects, question sets and tests using the account's own question bank.

If you are a client account administrator (managing candidates, sessions, results), refer instead to the [Account administrator manual](/ai/).

## Reaching the module

After logging in, you land in the **candidate module** (dashboard, candidates, results). To switch to the Question Module, open the module switch cards at the bottom of the left menu and click **Item management**. The **Candidate Management** card takes you back. The module is available to administrators holding the question-reading privilege.

The left menu of the Question Module has the following entries:

| Menu | Contents |
|---|---|
| **Items** | The question list, and a submenu **Response scales**. |
| **Subjects** | The subject list. |
| **Tags** | Submenu **Item sets** and **Domains**. |
| **Tests** | The list of tests built from your questions. Shown to administrators holding the test-reading privilege. |
| **Visual aids** | Images and reference documents shared between questions. |
| **System** | **Select an AI** — choose the AI model used by the assistance features. |

> 💡 **Interface wording** — On the English interface, questions are called **items** ("Item management", "Item sets"). This manual uses the word *question* throughout.

## Content architecture

The platform organises assessment content into several nested layers:

- **Subjects** — a subject is an assessable content area (Excel, Python, Internal procedures…). It is the reference unit for creating a test.
- **Domains** — break a subject down into broad skill areas ("Tables and charts", "Calculation functions") so reports can show a score per skill.
- **Question sets** — organisational bundles of questions, usable when composing a test.
- **Questions** — the items themselves, attached to a subject, a domain and optionally a question set.
- **Visual aids** — images and documents reusable from one question to another.
- **Answer scales** — reusable lists of answer options (Likert, frequency, etc.).
- **Tests** — assemble questions into a deliverable that candidates can take.

> 💡 **Where to start?** — If you are new to the tool, begin with the **[Subjects](/ai/en/question-module/subjects/)** chapter: it is the gateway to the entire content chain.
